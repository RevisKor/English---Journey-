# English Journey Lesson Archetype System

## Governing Rule

English Journey has a **predictable route through the product** but not a repetitive route through every lesson. The learner should always be able to answer four questions at a glance:

> **What is this? What do I do? What matters? What comes next?**

The curriculum architect selects the lesson’s dominant experience from its objective, topic, prerequisite state, retrieval needs, module position, and forward links. An archetype is therefore a **design decision**, not a decorative label or a mechanical rotation slot.

## Lesson Archetypes

| Archetype | Dominant learner experience | Best used when | Typical stages, selected rather than required | Avoid when |
|---|---|---|---|---|
| **Discover** | Meet a new idea through an image, situation, or short encounter. | New concrete language needs an intuitive first connection. | Orientation, encounter, light practice, next bridge. | The target is abstract enough to need explicit comparison first. |
| **Notice** | Compare examples and identify a meaningful difference. | Learners can already understand the context but need to see a form, use, or register contrast. | Retrieval, encounter, notice, one explained check. | It would introduce too many new items at once. |
| **Vocabulary** | Learn a small, coherent word set and use it immediately. | A topic-specific lexical base unlocks later interaction. | Encounter, word exploration, pronunciation, supported use, retrieval. | It would become a long unconnected word list. |
| **Grammar** | Build a useful pattern from meaning to controlled use. | A pattern blocks clear communication or recurs across the module. | Context, notice, worked model, supported construction, meaningful use. | The learner only needs one fixed phrase for the immediate task. |
| **Listening** | Listen for a purpose, then act on what was understood. | A spoken exchange, sound distinction, or detail is the real learning goal. | Orientation, listen, focused replay, evidence, next bridge. | A transcript would do all the work before listening begins. |
| **Speaking** | Rehearse and adapt short, useful spoken language. | Spoken confidence, rhythm, or interactional choice needs attention. | Model, word-only or line audio, repeat, substitute, self-check. | It would pretend to score pronunciation without reliable evidence. |
| **Reading** | Read an appropriately levelled text for a clear reason. | Language can be met through a meaningful short text, sign, message, or passage. | Reading purpose, read, optional support, comprehension, transfer. | The text exists only to hide a grammar drill. |
| **Writing** | Plan and create an intentional written message for a reader. | Learners need to express a concrete meaning in writing. | Purpose, model or checklist, draft, revise, reflection. | The task requires language not yet introduced or supported. |
| **Interaction** | Take turns in a plausible conversation and make choices. | The lesson target is responsive, social, or pragmatic. | Situation, exchange, choice, feedback, alternate response. | Both speakers merely read identical scripted lines. |
| **Real World** | Interpret or produce a useful everyday artefact. | A timetable, menu, message, form, sign, map, review, or request gives the target purpose. | Context, artefact, task, response, reflection. | The artefact is visually busy but has no learning reason. |
| **Integration** | Combine previously learned language in a new task. | The module needs an authentic “use what you know” lesson. | Light retrieval, task, limited support, evidence, forward bridge. | It adds a major new grammar point at the same time. |
| **Review** | Retrieve, reconnect, and repair earlier learning. | Spacing and weak-point support matter more than novelty. | Recall, feedback, short transfer, source link, plan. | It becomes a duplicate of the previous quiz. |
| **Assessment** | Demonstrate a stated can-do independently and fairly. | There is enough taught evidence to make a judgement meaningful. | Brief, independent evidence, transparent result, next step. | The task tests unexplained language or accidental test-taking tricks. |

## Selecting an Archetype

The architect completes this decision record before authoring content.

| Decision question | Design consequence |
|---|---|
| Is the outcome recognition, understanding, controlled production, interaction, or independent performance? | Select the archetype that makes that outcome the learner’s main action. |
| Is the lesson introducing, consolidating, connecting, or checking knowledge? | Prefer Discover/Vocabulary/Grammar for introduction, Integration/Review for consolidation, and Assessment only for valid checking. |
| What did the previous lesson leave unfinished? | Use the next lesson to extend, contrast, or retrieve that language naturally; do not repeat its structure by default. |
| What does the next lesson need? | Create a forward bridge only when the present lesson provides a genuine prerequisite. |
| What is the learner’s cognitive load? | Choose **light**, **normal**, or **deep** density; do not fill a lesson merely to look substantial. |
| Is older vocabulary needed naturally? | Include it only if it supports the present meaning. Otherwise retrieve it later in a better context. |

## Stages Are a Toolkit, Not a Mandatory Script

The navigation shell is stable, but an author may select only the stages that serve the lesson. A short Listening lesson might be `orientation → listen → focused replay → evidence`; a deep Grammar lesson may need `encounter → notice → model → supported construction → meaningful use`; an Integration lesson may begin with `retrieval → task` and introduce no new language at all.

> A lesson that omits a stage is not incomplete. It is complete when its chosen evidence genuinely demonstrates its stated can-do outcome.

## Density and Progressive Disclosure

| Density | Typical effort | Use when | Progressive-disclosure rule |
|---|---:|---|---|
| **Light** | 10–15 minutes | Retrieval, one listening contrast, short interaction, quick real-world task, or focused review. | Present one immediate action; keep support behind optional “Need help?” controls. |
| **Normal** | 15–25 minutes | Most single-objective learning experiences. | Reveal explanation after encounter or first attempt; keep examples near the action that needs them. |
| **Deep** | 25–40 minutes | A module hinge, demanding writing/reading, integrated practice, or carefully scaffolded grammar. | Divide into named milestones with one visible next action, optional supports, and a clear stopping point. |

Rich curriculum data is stored for authors, quality assurance, support, and adaptation. It is **not** a reason to show all information to the learner at once. A1 learners see the next purposeful action first; translations, tips, examples, technical notes, and full explanations appear progressively when they remove a real barrier.

## Variation Guardrails

The course does not force a numerical rotation such as “vocabulary, grammar, reading, writing”. Instead, the audit flags patterns that merit an author’s attention.

| Check | Alert condition | Required review, not automatic repair |
|---|---|---|
| Archetype concentration | A module has no meaningful variation or one archetype overwhelms the module without an educational reason. | Confirm that objectives genuinely require the concentration. |
| Repeated openings | Adjacent lessons reuse the same mentor move or generic motivation. | Rewrite the opening around a specific situation, question, tension, or learner promise. |
| Repeated activity sequence | Several nearby lessons use the same encounter-to-drill-to-quiz path. | Change the dominant experience or remove unneeded stages. |
| Repeated dialogue shape | Exchanges keep the same turns and names despite different purposes. | Change the social goal, response choice, register, artefact, or speaker relationship. |
| Assessment monotony | One question form becomes the default measurement. | Add the valid evidence form that best matches the can-do outcome. |
| Forced retrieval | Older language appears unnaturally just to satisfy a count. | Remove it and schedule retrieval in a context where it has a communicative purpose. |

## Level Evolution

| Band | Scaffolding and content complexity | Expected archetype evolution |
|---|---|---|
| A1–A2 | Concrete contexts, strong modelling, Arabic support for real hurdles, short turns, bounded novelty. | Discover, Vocabulary, Speaking, Interaction, short Reading, light Writing, Review. |
| B1–B2 | Longer connected text, choice, perspective, pragmatic contrast, learner planning, more independent repair. | Notice, Reading, Real World, Interaction, Writing, Integration, Assessment. |
| C1–C2 | Nuance, register, source evaluation, ambiguity, synthesis, rhetoric, precise self-editing. | Deep Reading, Writing, Real World, Integration, Notice, advanced Assessment. |

The visual shell remains recognisable from A1 through C2. What changes is not the navigation grammar but the **depth of thinking, amount of learner independence, text complexity, and precision of evidence**.
