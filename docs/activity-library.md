# English Journey Activity Library

## Activity selection principle

Activities are selected because they provide the right evidence or practice for a capability, not because a lesson needs decorative variety. The same target should appear in different meaningful forms across the course: encounter, notice, supported use, retrieval, contrast, and independent use.

| Activity family | Suitable level range | Main purpose | Examples | Avoid when |
|---|---|---|---|---|
| Picture-word match | A1–A2 | Establish concrete meaning | Food, objects, places, occupations | Abstract lexical distinctions need context rather than images |
| Listen and select | A1–B2 | Build sound–meaning connection | Minimal pairs, short exchanges, key details | The task can be solved by visual position or pattern alone |
| Dialogue completion | A1–C1 | Practise interaction routines and pragmatics | Greetings, requests, clarification, disagreement | All options are obviously wrong or artificial |
| Sort and classify | A1–B2 | Notice semantic/category relations | Count/non-count, adjective order, word families | Categories have not been explained or are culturally unclear |
| Pattern transformation | A1–B2 | Build controlled language accuracy | Positive/negative/question forms, time reference | It replaces all communicative use |
| Information gap | A2–C2 | Require real interaction and clarification | Schedules, plans, preferences, problem-solving | The learner can complete it without interpreting the partner’s information |
| Reading for task | A1–C2 | Develop purpose-driven comprehension | Find a time, infer an attitude, compare sources | A long text exists only to display vocabulary |
| Writing with model | A1–B1 | Scaffold genre and accuracy | Message, invitation, review, short account | The model is copied with no independent choice |
| Writing with rubric | B1–C2 | Develop independent drafting and revision | Opinion paragraph, email, report, synthesis | Feedback cannot be connected to clear criteria |
| Pronunciation contrast | A1–C2 | Build intelligibility and listening discrimination | /ɪ/ vs /iː/, stress, connected speech | It claims automatic accent scoring without such capability |
| Real-world item | A1–C2 | Transfer course language to an authentic genre | Notice, form, menu, timetable, email, review | The item adds cultural noise but no language purpose |
| Recall grid / quick review | A1–C2 | Strengthen delayed retrieval | Word-bank recall, old/new contrast, error repair | It simply replays the same question bank |
| Guided external-AI prompt | A2–C2 | Let a learner-owned AI generate or review extended work | Reading passage prompt, writing-feedback prompt | It sends private learner data without clear consent or becomes required for core completion |

## Rotation guardrails

For each module, include at least one receptive task, one productive task, one interaction or speaking-oriented task where level-appropriate, one retrieval task, and one real-world or transfer task. Do not repeat a dominant activity family in consecutive lessons unless the second lesson explicitly deepens rather than duplicates the first.

## Feedback patterns

| Feedback type | Suitable activity | Minimum feedback content |
|---|---|---|
| Explanatory correction | Objective language, vocabulary, and listening items | Correct answer, reason, and a contrast with the misconception |
| Hint then retry | Guided practice | One relevant cue before revealing the answer |
| Worked comparison | Grammar and register activities | Why one option fits the context better than the alternatives |
| Rubric reflection | Writing/speaking | Content, organisation, language use, and level-appropriate next step |
| Retrieval scheduling | Review | Source lesson, confidence cue, and next review opportunity |
