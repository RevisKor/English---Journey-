# A1 Lessons 1–5: Archetype Application Record

## Status and purpose

This record amends the earlier A1 Lessons 1–5 sample. It makes the authoring decision explicit: the five lessons share a predictable navigation grammar, but they are **not five copies of the same lesson layout**. Before live authoring, each lesson is given a dominant archetype, an appropriate density, selected stages, and deliberately omitted stages.

> The learner always sees: **what this is → what I do now → what matters → what comes next**. The learner does not always see the same activity sequence.

## At-a-glance authoring map

| Lesson | Dominant archetype | Density | What the learner does first | Why this form is right now | Intentionally not required |
|---|---|---|---|---|---|
| 1. A First Hello | **Discover** | Normal | Listen to a tiny meeting and choose a greeting. | The first need is confidence in a real social moment, not a terminology lesson. | Extended grammar, formal writing, long reading. |
| 2. My Name Is… | **Interaction** | Light | Answer a classmate’s name question in a guided exchange. | The purpose is turn-taking; `my` and `your` are more memorable inside a real exchange than in a rule panel. | Separate reading passage, long explanation, independent paragraph. |
| 3. I Am / You Are | **Grammar** | Deep | Compare an Arabic and English identity sentence, then build one. | This is an early structural hinge with a likely Arabic-speaker transfer issue; it deserves a slower contrast and explanation. | Large lexical topic, full role-play performance, unrelated assessment. |
| 4. People Around Us | **Visual Vocabulary** | Light | Hear one word, choose the correct person in a picture, then make a caption. | Image, sound, and label are the main learning evidence; a long introduction would distract from the task. | Long mentor message, independent writing, full grammar rule. |
| 5. Listen, Repeat, Meet | **Speaking Integration** | Normal | Select a role-play mode and rehearse a four-line introduction. | The lesson demonstrates usable learning through integration; it should retrieve existing language instead of adding a new grammar point. | New word list, new grammar explanation, end-of-lesson multiple-choice quiz. |

## Shared navigation, different layouts

| Stable element | Learner-facing question answered | How it varies by archetype |
|---|---|---|
| Purpose card | **What is this?** | “Your first hello,” “A name exchange,” “A pattern workshop,” “Picture English,” or “A mini-conversation.” |
| Next action | **What do I do?** | Listen and choose; reply; compare and build; point and label; role-play. |
| Importance cue | **What matters?** | Social confidence; knowing someone’s name; choosing `am/are`; linking sound to person; being understood. |
| Forward bridge | **What is next?** | A next conversation, a grammar contrast, a picture caption, or an integration task. It appears only when it provides a genuine reason to continue. |
| Support controls | **What if I need help?** | Arabic help, a model, a worked example, a transcript, a word-only audio button, or a “Watch out” note are revealed when useful, never dumped on the opening screen. |

## Lesson 1: A First Hello

| Design field | Authoring decision |
|---|---|
| First view | **Discover: A First Hello**. The learner taps one 10-second class encounter. The only immediate action is “Listen and choose the greeting.” |
| Chosen stages | Encounter → word exploration → word-only sound practice → guided choice → short recall. |
| Core activity pattern | Hear `hello`, `thank you`, and `goodbye` in a small exchange; tap the phrase that fits each social moment; say one two-line exchange with a model. |
| Explicitly omitted | A formal grammar panel and a writing task. A sentence-capital note may appear as a tiny optional “Helpful tip,” not as a second lesson inside this one. |
| Evidence | Choose the appropriate opening or closing and complete one supported greeting. |
| Visual emphasis | **Discover** marker: compass icon, quiet warm accent, label “Your first English moment / أول موقف إنجليزي لك.” |

## Lesson 2: My Name Is…

| Design field | Authoring decision |
|---|---|
| First view | **Interaction: Meet Noor**. Noor asks, “Hello. What is your name?” The learner chooses to speak, type, or rehearse silently. |
| Chosen stages | Light retrieval → guided turn → notice `my/your` inside turns → conversation repair → one exit line. |
| Core activity pattern | The learner takes alternating turns; an incorrect `my/your` choice receives an explained response and the turn is repeated naturally. |
| Explicitly omitted | A detached vocabulary-table opening, long rule explanation, and comprehension passage. The word meanings appear only when a learner taps them. |
| Evidence | Complete a four-line name exchange; the system checks whether the meaning of `my` and `your` fits the speaker, not merely whether one option was memorised. |
| Visual emphasis | **Interaction** marker: conversation icon, restrained teal accent, label “Take your turn / خذ دورك.” |

## Lesson 3: I Am / You Are

| Design field | Authoring decision |
|---|---|
| First view | **Grammar studio: Make the connection**. Two short statements appear: `أنا طالب` and `I am a student.` The learner notices the extra English word before any explanation. |
| Chosen stages | Meaning contrast → worked model → focused word-bank → construction ladder → one meaningful sentence → independent evidence. |
| Core activity pattern | Drag meaningful chunks, not isolated letters; choose `am` or `are` after choosing the person; write or say one true or imagined identity statement. |
| Explicitly omitted | A new topical vocabulary set, an extended narrative reading, and a performance dialogue. The lesson is deep because one pattern needs careful attention, not because every deep lesson needs every skill. |
| Evidence | Build and explain one `I am` sentence and one `You are` sentence. Feedback names the relationship: `I → am`, `you → are`. |
| Visual emphasis | **Grammar** marker: puzzle-piece icon, restrained violet accent, label “Notice the pattern / لاحظ النمط.” A contrast table has text headings and example arrows; colour never carries the distinction alone. |

## Lesson 4: People Around Us

| Design field | Authoring decision |
|---|---|
| First view | **Visual Vocabulary: Picture English**. Three simple person cards appear. The learner hears a word and selects the matching card. |
| Chosen stages | Audio-image encounter → image labelling → point-and-say → caption building → fast visual recall. |
| Core activity pattern | Hear, recognise, tap, repeat the **word only**, then build `This is a woman.` from meaningful chunks. The image changes while the language is reused. |
| Explicitly omitted | A long mentor introduction, broad `a/an` instruction, an independent writing task, and a formal final quiz. One useful caption chunk is enough for the immediate outcome. |
| Evidence | Identify a person from audio and create one correct caption. |
| Visual emphasis | **Vocabulary** marker: book-open icon, restrained blue accent, label “Words to use / كلمات تستخدمها.” Arabic labels remain behind a learner-controlled support control. |

## Lesson 5: Listen, Repeat, Meet

| Design field | Authoring decision |
|---|---|
| First view | **Speaking Integration: Your first mini-conversation**. The learner picks “Listen first,” “Practise with a model,” or “Try it now.” |
| Chosen stages | Retrieval chain → whole-model listen → line rehearsal → role-play choice → communication self-check → optional second attempt. |
| Core activity pattern | The learner puts earlier language to work in a new classmate scenario. The model is available, but the learner may gradually hide it. The learner chooses spoken, typed, or silent rehearsal. |
| Explicitly omitted | New lexical teaching, a new grammar panel, and a default multiple-choice quiz. The evidence is communicative: can the learner greet, give a name, add one fact, and close politely? |
| Evidence | A four-line spoken or typed exchange, followed by a learner-controlled checklist: greeting present, name present, one fact present, polite close present. No fake accent scoring. |
| Visual emphasis | **Speaking** marker: microphone icon, restrained coral accent, label “Try it aloud / جرّبه بصوتك.” The assessment surface remains neutral and uses a check-circle icon plus text label. |

## Variation and quality review

| Requirement | How Lessons 1–5 meet it |
|---|---|
| No universal layout | The five lessons have Discover, Interaction, Grammar, Visual Vocabulary, and Speaking Integration as distinct dominant experiences. |
| Stage selection, not stage completion | Every lesson explicitly omits stages that would dilute its objective. |
| Light, normal, and deep density | Lessons 2 and 4 are light; Lessons 1 and 5 are normal; Lesson 3 is deep. |
| Varied activity patterns | Social choice, turn-taking, contrast and construction, audio-to-image mapping, and role-play integration are different activity structures. |
| Calm semantic visual language | Labels, icons, and modest accents distinguish activity types; the main interface stays neutral and readable. |
| Progressive disclosure | The first view has one task; Arabic help, explanations, transcripts, and extended examples appear only when needed. |
| Natural retrieval | Earlier language returns when it helps a new social action, never merely to fill a quota. |

## Fixed constraint for the remaining A1 authoring

Future A1 lessons must not copy the headings, mentor opening, dialogue shape, activity order, or question format of these five examples. They must preserve the same learner clarity and semantic visual language while making an explicit, auditable archetype decision from the lesson objective and curriculum graph.
