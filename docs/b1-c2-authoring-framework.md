# English Journey: B1–C2 Authoring Framework

This framework turns the A2 six-step lesson model into a repeatable, cumulative system for higher levels. It is an internal production guide: it sets the scope, standards, and evidence required before any B1–C2 module is released.

## Non-negotiable design rules

Every new lesson must reactivate selected language from earlier levels before introducing its own target language. Authors should therefore define three small sets for each lesson: **retrieve** (two to four earlier chunks or grammar patterns), **extend** (new vocabulary, collocations, grammar, or discourse functions), and **transform** (a learner task that requires the old and new language together). Content should prioritize phrases, word families, collocations, register, and communicative purpose over alphabetical word lists.

| Requirement | Minimum release evidence |
|---|---|
| CEFR focus | Can-do outcome, reading/writing length, grammar/discourse range, and assessment threshold are explicitly defined. |
| Cumulative learning | Every lesson references earlier material through a retrieval target and an observable transfer task. |
| Lexical depth | Each lexical network includes a core meaning, collocations, word family, register note, common Arabic-speaker issue, and reusable examples. |
| Originality | Readings, prompts, explanations, and assessment items are original English Journey content; external material is used only when licensed and attributed. |
| Arabic support | Arabic explains difficult distinctions and feedback, but English carries an increasing share of instructions and task content. |
| Validation | Dataset schema, coverage, duplicates, sentence quality, accessibility, mobile rendering, and automated progress rules all pass before release. |

## Level architecture

| Level | Suggested structure | Core shift | Reading pathway | Writing milestone |
|---|---:|---|---|---|
| B1 | 24 lessons / 4 modules | From familiar topics to connected narratives, opinions, and practical problem-solving | 250–350-word articles, emails, interviews, and stories | 140–180-word email, review, narrative, or opinion paragraph |
| B2 | 24 lessons / 4 modules | From communicating clearly to arguing, comparing, qualifying, and adapting register | 450–650-word analysis, feature, review, and workplace text | 220–280-word proposal, report, article, or balanced argument |
| C1 | 20 lessons / 4 modules | From accuracy to precision, nuance, synthesis, and persuasive control | 700–900-word essays, long-form journalism, lectures, and reports | 450–650-word source-informed essay, briefing, or critique |
| C2 | 16 lessons / 4 modules | From advanced proficiency to flexible, culturally aware mastery | 900–1,200-word literary, academic, or policy text with competing viewpoints | 700–1,000-word synthesis, editorial, critical response, or professional strategy document |

## Lesson design by level

The visible **six-step route** remains consistent so that learners always know how to progress. What changes is the intellectual demand.

| Step | A2 baseline | B1–B2 development | C1–C2 development |
|---|---|---|---|
| 1. Start here | Recall familiar language | Diagnose assumptions, prior experience, and stance | Frame a question, claim, or competing interpretation |
| 2. Explore | Chunks and word families | Collocations, connotation, formality, and word choice | Semantic precision, rhetorical effect, allusion, and disciplinary language |
| 3. Notice | Grammar in examples | Grammar and discourse patterns across a short text | Stylistic choices, hedging, cohesion, and argument architecture |
| 4. Build | One connected idea | A structured paragraph, comparison, story segment, or spoken turn | A nuanced claim, synthesis, counterargument, or controlled style shift |
| 5. Respond | Guided reading and questions | Interpret a source, compare viewpoints, or solve a practical task | Critically evaluate evidence, bias, implication, and rhetorical strategy |
| 6. Prove it | Short writing plus quiz | Meaningful output plus module performance task | Portfolio-quality writing, speaking brief, peer-style critique, or timed capstone |

## English-first scaffolding schedule

Arabic stays available as a precision tool rather than disappearing abruptly. The user controls an **Arabic help** toggle throughout the course.

| Course stage | Instruction default | Arabic role |
|---|---|---|
| A2 | English task direction followed by Arabic clarification | Explain false friends, grammar contrasts, and AI feedback |
| B1 | English-first instructions, Arabic on demand | Clarify complex grammar and high-impact feedback only |
| B2 | English instructions and readings by default | Support sophisticated meaning, register, and error diagnosis |
| C1–C2 | English-only learning surface by default | Optional translation or contrastive note, never a parallel duplicate lesson |

## Content packs per lesson

Each higher-level lesson should ship as one coherent package rather than a word list plus unrelated grammar.

1. A real-world **scenario** and explicit can-do outcome.
2. A lexical network of 8–12 high-value items, 6–10 collocations/chunks, word families, register notes, and prior-level links.
3. One grammar or discourse move shown in authentic-seeming context.
4. An original controlled reading or listening-ready script at the appropriate length.
5. A purposeful written or spoken response task with audience, purpose, and success criteria.
6. A short lesson check and a cumulative module performance task.
7. AI tutor guardrails that specify level, permitted complexity, multilingual feedback policy, and concise response limits.

## Assessment and release gates

Lessons retain an 80% objective-check threshold. Higher-level progress should not rely on multiple choice alone: module tests combine controlled language checks with an AI-graded written response and an interpretation task. AI scoring must return structured feedback, an Arabic explanation when help is enabled, and a revision path; it must never silently decide progression without presenting the learner’s result.

Before implementation, each level should be delivered in the sequence **curriculum specification → authored module sample → validation scripts and tests → mobile/UI review → pilot feedback → remaining modules**. This keeps quality high, prevents content debt, and lets the six-person pilot guide which explanations and activities are most useful.
