# C2 Module 11 Architecture

Module 11 (Lessons 151–165) moves from the completed C2 capstone into public memory, inherited responsibility, archives, restitution, language policy, testimony, and repair. The dominant experience is mediation across unequal histories. Every lesson has one primary objective and one bilingual retrieval check; reading and interaction carry the evidence work, while writing and assessment ask the learner to preserve uncertainty and affected perspectives.

The module is not a rotation. Its arc is: notice how records are made, test what they omit, mediate competing histories, design repair language, and produce a responsible public record.
