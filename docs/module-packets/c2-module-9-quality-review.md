# C2 Module 9 Quality Review

## Scope

Module 9 covers Lessons 121–135 and develops epistemic responsibility, plural futures, and accountable deliberation. The module is authored as compact bilingual English/Arabic learning journeys rather than a repeated lesson template.

## Pedagogical review

Each lesson has one primary objective and one explicit bilingual retrieval check. The arc moves from separating probability from proof, through calibration and complementary knowledge, into scenario framing, long-horizon reasoning, intergenerational responsibility, and collective decision-making. The sequence deliberately varies reading, listening, interaction, speaking, standard language work, writing, review, synthesis, and assessment rather than rotating skills mechanically.

The module includes source-aware reading activities, a two-scenario writing brief, listening work on uncertainty and intergenerational responsibility, and interaction tasks that surface missing evidence and value choices. The final transfer assessment asks the learner to mediate evidence, state assumptions, compare futures, and recommend an accountable collective choice.

## Bilingual and retrieval review

Every authored activity contains English and Arabic objective language, and every activity contains a retrieval prompt with Arabic support and expected evidence. Retrieval links prior C2 work on narrative reliability, ethical persuasion, systems thinking, memory, economics, and institutional language without forcing old vocabulary into every task.

## Progressive disclosure and visual review

Listening activities expose transcript support progressively rather than placing the full script in the first view. Experience records provide bilingual first-view guidance answering what the activity is, what the learner should do, what matters, and what comes next. Detailed rationale, worked examples, Arabic help, and external-AI prompts remain supporting layers rather than competing with the primary objective.

## Assessment review

The module includes a checkpoint at Lesson 130 and a cumulative transfer assessment at Lesson 135. The final assessment is not a recognition quiz: it requires evidence qualification, scenario comparison, explicit value reasoning, and a consequential recommendation. Writing remains compatible with the project’s no-per-request-AI-cost policy through an external-AI grading prompt rather than an embedded model call.

## Engineering review

The C2 pipeline gives Module 9 authored activities and experiences precedence for Lessons 121–135 while preserving completed Module 1–8 overrides and legacy fallback behavior elsewhere. Focused C2 regressions cover 15 authored lessons, activity-kind diversity, bilingual retrieval, first-view completeness, reading and writing cadence, listening transcript disclosure, and final assessment semantics.

The release gate passed with 50 Vitest files and 279 tests, TypeScript checking, production build, curriculum audit, and rearchitecture audit. The recurring development database SSL synchronization warning is external to curriculum source changes and remains unrelated to this milestone.

## Review decision

Module 9 is accepted for checkpointing. The next curriculum milestone is C2 Module 10, the final authored module in the current 180-lesson C2 structure. Vercel deployment and administrator-role verification remain evidence-gated external tasks and are not represented as complete by this review.
