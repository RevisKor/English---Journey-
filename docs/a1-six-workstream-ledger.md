# A1 Six-Workstream Authoring Ledger

**Purpose.** This is the production-control ledger for the A1 rewrite. A lesson moves to **Approved** only when all six workstreams have supplied their required evidence in the live course data, its assessment bank, and the learner route.

> **Current truth:** The first five lessons have a written review sample in `a1-lessons-1-5-authored-sample.md`. They are not marked as live-production approved until their complete content is integrated, tested, and reviewed. All other lessons remain pending authoring.

## Status Vocabulary

| Status | Meaning |
|---|---|
| **Pending** | No lesson-level content production has started. |
| **Draft sample** | A written model exists for review, but it is not yet integrated into the live data and assessment bank. |
| **In authoring** | The designated workstreams are producing the required lesson evidence. |
| **In independent review** | Content is integrated and awaiting audit, content/level review, and learner-route checks. |
| **Approved** | All six workstream checks pass and the lesson is included in a versioned batch checkpoint. |

## Required Evidence Fields

| Workstream | Ledger evidence |
|---|---|
| Curriculum architecture | Module objective, lesson can-do, prerequisite retrieval target, forward retrieval link, and exact lesson role. |
| Pedagogy and Arabic support | Controlled language set, English/Arabic explanation, Arabic-speaker risk note, examples, scaffold fade, and mastery condition. |
| Activity and UX | Ordered learning sequence, pronunciation action, dialogue/reading/writing brief as applicable, transition text, and accessibility notes. |
| Assessment | Item blueprint, valid distractor rationale, productive evidence where appropriate, feedback rule, and module-test link. |
| Visual language | Necessary visual or interaction brief, captions/alt-text, and explanation of the learning purpose. |
| Independent QA | CEFR scope check, repeated-exposure check, bilingual clarity check, content/quiz alignment check, audit result, and regression-test result. |

## Module-Level Approval Gate

A module moves from **In authoring** to **Approved** only when every lesson row is approved, its vocabulary has planned contextual returns, all assessment items trace to taught material, the module checkpoint samples the module’s stated can-do outcomes, and the learner workspace demonstrates the intended sequence without a navigation dead-end.
