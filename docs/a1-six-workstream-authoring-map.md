## What “Reauthored” Means

A lesson is **not** marked complete merely because it has a title, word list, grammar label, or generic helper text. The six workstreams must produce verifiable evidence in the lesson data and learner route.

| Workstream | Required authored evidence for every lesson | Completion test |
|---|---|---|
| 1. Curriculum architect | A clear module role, a can-do outcome, prerequisite retrieval, forward link, and no duplicated learning objective. | The lesson has explicit graph links and fits the module progression. |
| 2. Language-learning specialist | Beginner-safe English and Arabic explanation, Arabic-speaker risk note, controlled examples, and a defined mastery threshold. | A learner with no grammar terminology can explain what to do and why. |
| 3. Activity/UX designer | A deliberate learn → notice → use → retrieve sequence, a pronunciation action, and a transition that leads naturally to the next activity. | The learner does not need to choose an arbitrary tab or invent the next step. |
| 4. Assessment designer | Contextual vocabulary and grammar items, misconception distractors, mastery feedback, and an assessment role appropriate to the lesson. | Items require choosing language in context; they do not reward spelling traps or answer-position guessing. |
| 5. Visual-language designer | A concrete visual or interaction brief where it improves meaning, with accessible caption/alt-text direction. | Visual material teaches a meaning, contrast, action, or situation rather than decorating the page. |
| 6. QA/research reviewer | Source/claim record where applicable, CEFR scope check, repeated-exposure check, bilingual clarity review, and machine-audit result. | No unresolved severity-1 issue; the lesson remains consistent with its module and level. |

## Batch Sequence

Each A1 module is produced as a closed authoring batch. The six workstreams work from one shared module ledger; they do not independently overwrite the same lesson fields.

1. **Map the module arc.** Confirm the 15 lesson outcomes, prerequisite links, retrieval points, capstone task, and module-test coverage.
2. **Write lesson blueprints.** Replace generic activity text with specific mentor transitions, explanations, examples, prompts, dialogue/reading briefs, pronunciation instructions, and review prompts.
3. **Build assessment evidence.** Produce or revise the lesson question bank and module checkpoint around the vocabulary, grammar, and communication outcome actually taught.
4. **Apply visual-language briefs.** Attach image/scene/interaction guidance only where it supports comprehension or performance.
5. **Run independent review.** Check lesson sequence, duplicate items, Arabic quality, CEFR scope, assessment validity, and route rendering.
6. **Checkpoint only the completed module.** A batch is not carried forward as “complete” until all 15 lessons pass the same gate.
