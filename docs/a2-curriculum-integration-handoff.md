# A2 Curriculum Integration Handoff

## Purpose and current state

The authored A2 expansion is a **review-ready shadow inventory**. It contains **nine thematic modules with fifteen lessons each (135 lessons total)**, and it is intentionally separate from the normalized learner catalog. The active catalog, learner progress gates, quiz assignment, and completion records remain unchanged until an explicit migration is approved.

| Property | Current A2 status | Learner impact now |
|---|---|---|
| Authoring source | `shared/course/a2-immersive-authoring.ts` | None; source is read-only curriculum data |
| Blueprint builder | `shared/course/progressive-immersive.ts` | Exposes A2 as guided, bilingual authoring blueprints |
| Owner review | `ImmersiveCurriculumInventory` in Content Review | Administrators can inspect all nine modules and migration records |
| Migration records | `buildProgressiveImmersiveMigrationPlan("A2", 0)` | Marked `shadow-preview`, not published lessons |
| Active course catalog | Existing normalized catalog | Remains the only source for learner routing and progress |

> **Safety boundary:** A shadow-preview module must never be treated as an active catalog module merely because it is visible in Content Review. Publication requires explicit catalog synchronization and verification.

## A2 module sequence

The sequence deliberately moves from supported, high-frequency interaction toward connected language, practical writing, and clearer self-correction.

| Module | Theme | Communicative outcome | Checkpoint focus |
|---:|---|---|---|
| 1 | Health and Habits | Describe routines, symptoms, and helpful changes | Advice, reason, present/past control |
| 2 | Learning and Work | Discuss responsibilities, progress, skills, and goals | Experience, plans, comparison |
| 3 | Travel and Services | Manage short trips, requests, directions, and problems | Practical service interaction |
| 4 | Stories and Memories | Build a clear past narrative and describe reactions | Narrative sequence and paragraph cohesion |
| 5 | Nature and Community | Describe rules, places, conditions, and local proposals | Suggestions and problem–solution writing |
| 6 | Choices and Plans | Compare options and give supported recommendations | Contrast, future plans, and negotiation |
| 7 | Communication and Technology | Clarify meaning and resolve everyday digital problems | Messages, paraphrase, and instructions |
| 8 | Food, Shopping, and Services | Compare products and manage service exchanges | Quantities, repair language, and formal complaint |
| 9 | Celebrations and Culture | Discuss invitations, traditions, feelings, and differences respectfully | Cultural comparison and respectful response |

Every module retains the established repeated-exposure loop: introduce language, encounter it visually or in a dialogue, retrieve it through speaking or reading, use it in writing, and consolidate it in review and a contextual checkpoint.

## Migration protocol

The proposed migration should be completed as a controlled, idempotent catalog synchronization—not as a direct replacement of existing rows. The source keys generated by `immersive-migration-plan.ts` are the durable provenance identifiers for each authored module and lesson.

| Step | Required action | Acceptance evidence |
|---:|---|---|
| 1 | Freeze the approved A2 source inventory and generate the migration plan with the real active A2 lesson count. | Nine module records, 135 lesson records, and no duplicate source keys. |
| 2 | Convert approved lesson blueprints into catalog payloads, preserving bilingual titles, activity type, vocabulary anchors, grammar focus, and mentor guidance. | All required catalog fields are populated; no fallback-only activity metadata. |
| 3 | Upsert modules, lessons, vocabulary, question-bank items, and assessments through an idempotent synchronization script. | A repeat run makes no duplicate records or unintended changes. |
| 4 | Rebuild active A2 module boundaries and gated lesson ordering only after row-count and provenance checks pass. | Exactly nine active A2 modules and 135 globally ordered A2 lessons. |
| 5 | Validate learner routing, word-bank provenance, contextual quizzes, milestone checkpoints, and administrator review. | Automated tests, typecheck, production build, and authenticated desktop/mobile review evidence. |
| 6 | Create a checkpoint before publishing the migrated catalog. | A rollback-safe project checkpoint is available. |

## Guardrails for future work

The migration must preserve the project’s no-per-request AI-cost architecture: reading, writing, and tutoring support remain external-prompt handoffs, while quizzes are deterministic contextual question-bank selections. A2 content should not introduce live model calls, fabricated learner results, or altered learner completion data.

Later-level targets remain unchanged: **B1 150 lessons, B2 150 lessons, C1 160 lessons, and C2 180 lessons**. Their authored models may continue to evolve in shadow preview until each level has equivalent vocabulary provenance, assessment coverage, and active-catalog synchronization checks.
