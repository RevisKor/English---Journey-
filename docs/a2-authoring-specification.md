# A2 Authoring Specification

## Purpose

This specification turns the A2 roadmap into a repeatable authoring contract. Every A2 lesson must develop **everyday independence**: learners should understand and create connected language about familiar life, experiences, plans, needs, and simple opinions. A2 is not an expanded A1 word list; it is the bridge from isolated sentences to connected communication.

## Lesson contract

| Requirement | Standard |
|---|---|
| Length | 45–60 minutes of guided study, excluding optional review |
| Structure | Six visible steps: Start, Explore, Notice, Build, Respond, Prove |
| New language | 20–25 varied targets: a mix of words, phrases, collocations, and functionally useful chunks |
| Retrieval | 3–5 A1 targets visibly reused in a new A2 context |
| Grammar | One main choice with meaning, form, pronunciation, Arabic contrast, common error, and communicative effect |
| Context | An original dialogue, story, dilemma, or practical scenario before isolated explanation |
| Production | One short personal or practical output linked to an audience and purpose |
| Assessment | A mastery check mixing retrieval, phrase choice, grammar in context, and one sentence-level transfer item |

## The six-step learner path

| Step | Authoring rule | Example: A2 travel-problem lesson |
|---|---|---|
| **Start** | Retrieve earlier language with a meaningful 90-second prompt | “You missed your bus. What can you say with A1 words?” |
| **Explore** | Put target language in an original situation | A traveller asks for help after a delayed train |
| **Notice** | Explain the language choice, not only the rule | “Could” softens a request; “can” is direct but still polite in many situations |
| **Build** | Progress from controlled to choice-based practice | choose request phrases, then adapt them to three situations |
| **Respond** | Require an outcome for a real audience | send a 70-word message explaining a delay and proposing a plan |
| **Prove** | Test transfer and schedule review | select the most appropriate phrase, correct a common Arabic-influenced error, and create one request |

## A2 module map

| Module | Lessons | Main communicative outcome | Grammar spine | Lexical network focus |
|---|---:|---|---|---|
| **A2.1 My life in motion** | 1–5 | Describe routines, preferences, health, and change | comparatives; frequency; present continuous vs. simple present; basic adverbs | habits, wellbeing, choices, feelings, comparison |
| **A2.2 People and places** | 6–10 | Describe people, neighbourhoods, services, and travel | quantity; basic relative clauses; place language; requests | city life, travel, services, description, directions |
| **A2.3 Experiences and plans** | 11–15 | Tell an experience and make future arrangements | past narrative; present perfect introduction; future forms; advice | memories, invitations, problems, celebrations, plans |
| **A2.4 Choices and communication** | 16–20 | Give a reason, solve an everyday issue, and express an opinion | modals; linkers; first conditional; opinion frames | media, work/study, shopping, technology, local life |

## Arabic-speaker support rules

Arabic support is targeted rather than constant. The default presentation is English plus an optional Arabic explanation. Use Arabic contrast when it prevents a predictable transfer error, especially with articles, auxiliary verbs, word order, present perfect, countability, prepositions, modal strength, and pronunciation features absent or differently distributed in Arabic. The AI should explain the contrast respectfully: “Arabic expresses this idea differently; English needs…” rather than treating Arabic as a mistake.

## Content quality and rights rules

All examples, passages, dialogues, definitions, and activities must be original English Journey material or based on explicitly open licences. Oxford and Cambridge tools are used only to verify CEFR fit and word/phrase importance. Every target should include a usable pattern or collocation, a British IPA transcription where available, an optional American playback route, and a sentence that demonstrates the target’s purpose.
