# Lesson-design evidence base

This register is an input to the Curriculum Bible, not content to copy.

| Source | Design principle | English Journey application | Boundary |
|---|---|---|---|
| [Council of Europe — CEFR Companion Volume](https://www.coe.int/en/web/common-european-framework-reference-languages) | Language users act, collaborate, mediate, and make meaning in context. | Define outcomes as observable can-do performances; increase independence, mediation, register, and discourse control by level. | Do not turn CEFR into grammar labels or word totals. |
| [British Council TeachingEnglish resources](https://www.teachingenglish.org.uk/teaching-resources) | Clear outcomes, purposeful task sequences, learner participation, and reflection support effective lessons. | Require objectives, first-view guidance, visible task purpose, and next-step bridges. | Consistent navigation must not create identical lesson pages. |
| [Victorian Department of Education — Evidence to Action](https://arc.educationapps.vic.gov.au/learning/sites/evidence-to-action/7794) | Retrieval and spaced review strengthen learning when they are effortful and relevant. | Retrieve language in later useful contexts and cumulative checks. | Never force old language into an unnatural scenario. |
| [Cognitive Load Theory: Sweller, Ayres & Kalyuga](https://link.springer.com/book/10.1007/978-1-4419-8126-4) | Limit unnecessary processing; sequence support and independent practice deliberately. | Use light/normal/deep density, worked examples, concise instructions, and progressive disclosure. | Appropriate depth is not overload when it has a clear purpose. |

## Decisions derived from the evidence

1. Outcomes describe a useful learner action, not a vocabulary list.
2. Retrieval returns because it helps the current task.
3. Support reduces as learner independence grows from A1 to C2.
4. Assessment checks transfer rather than recall of a memorised sentence.
5. The course uses familiar navigation but purpose-chosen lesson layouts.
